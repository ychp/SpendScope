# CodexVista 外观设计

改造现有「经典」「水墨」两款皮肤，经典支持浅色、深色和跟随系统，水墨仅支持浅色。切换水墨不会覆盖经典皮肤的色系偏好。保留原有信息结构、皮肤名称与偏好键。看板、菜单栏弹窗、设置与项目详情复用 `DesignSystem.swift`。

## 视觉与交互

- 经典：铝灰表面、钴蓝强调、DIN 大数字和额度环外刻度，卡片边角收紧。
- 水墨：雾白纸面、宋体标题与衬线大数字、朱砂印记和选中状态。横向额度笔触按实际剩余比例绘制，纸纹轻微且置于文字下方。额度区下沿加入远山、留白水面、一叶舟与岸边苇草；保持主要读数清晰。山水仅作装饰，不代表统计数据。
- 套餐列表跟随皮肤：水墨的当前套餐采用浅纸底、朱砂细边框与印章式徽标，说明文字和付费标签使用共享墨色与中性底色。
- 两款皮肤共享清晰的信息分组和 Token 分类文字，皮肤选择改为可点击的预览卡，入口仍为「设置 → 外观」。
- 高频分析页和时间范围即时切换。共享控件提供按压反馈，减少动态效果时不缩放。
- 日历最高等级使用完整强调色及对应高对比文字，其余有效日期使用完整主要文字色。
- 装饰无动画，不拦截操作；皮肤卡提供按钮语义和选中状态，额度条提供剩余量辅助功能标签。
