# CodexVista 双主题设计

暖白浅色与石墨深色共享信息结构，通过中性色建立层次，蓝色用于额度、趋势和交互强调。看板、菜单栏弹窗、设置与项目详情均复用 `DesignSystem.swift`。

| 色彩角色 | 暖白浅色 | 石墨深色 |
| --- | --- | --- |
| 窗口底色 | `#F3F2EF` | `#191A1D` |
| 面板表面 | `#FAFAF8` | `#222327` |
| 数据卡片 | `#FFFFFF` | `#292A2F` |
| 分隔与边框 | `#DFE0DC` | `#3B3D43` |
| 主要文字 | `#24262B` | `#EEEFF2` |
| 次要文字 | `#62666F` | `#ABAEB8` |
| 强调色 | `#345AC6` | `#91ACFF` |
| 控件选中底色 | `#FFFFFF` | `#44464F` |

## 视觉与交互

- 数据面板使用实色表面，去除光谱背景、玻璃反射和发光边缘，避免壁纸影响对比度。
- 数字沿用等宽数字排版，额度环内的百分比加大；Token 类别继续通过色点和文字共同区分。
- 分段控件使用中性选中底色；主操作按钮保留较深蓝色背景，保证白色文字清晰。
- 高频分析页和时间范围即时切换。共享控件提供即时按压反馈，减少动态效果时不缩放。
- 日历最深色格使用完整强调色，浅色模式配白字，深色模式配深灰字；其余有效日期使用完整文字色，避免叠加透明度降低对比度。
